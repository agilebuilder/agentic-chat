# Support policy

Use GitHub Issues for reproducible bugs and feature requests. Use the question form for integration guidance. Security and conduct reports must remain private.

Please include exact package versions, Node/React/TypeScript/browser versions, adapter capabilities, diagnostics with secrets removed, and a minimal reproduction. Maintainers may close issues that cannot be reproduced or fall outside the published support matrix.

Priority guidance:

- blocker: publishing, data integrity or broad security failure with no workaround;
- high: supported primary workflow is unusable or unsafe;
- medium: important defect with a workaround;
- low: cosmetic, documentation or narrow enhancement.

Open-source support is best effort. Commercial response times are not implied.
